Galactic Baking Adventure

If you're a space fan and you like generic alien characters with a wacky plot, you've come to the right place. I originally wanted to showcase my other text game which covered serious topics on parentification, but I lost my files. Thankfully though, I still had this gem that I made back when I was getting used to html. It took extremely long, and while not nearly as polished as my other sites, it's a cheerful and fun little game to go through and see all the different endings. The images may not work, so if you have that error there is a local folder on this computer "kim_textgame" that is already opened. Click index.html in the folder and start your journey!
